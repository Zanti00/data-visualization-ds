**Laboratory Activity**

**Student Enrollment Visualization**

Using Python:

1. Create a dataset containing enrollment data for 5 programs.  
2. Create a Bar Chart of student population.  
3. Create a Pie Chart showing percentage distribution.  
4. Create a Line Chart showing enrollment trend from 2016-2026.  
5. Create a Heatmap of correlations.  
6. Write a short interpretation for each visualization.

**Expected Learning Outcomes**

* Apply visualization techniques using Python.  
* Perform (EDA).  
* Interpret graphical results.  
* Create professional data science reports and dashboards.
